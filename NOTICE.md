# Notice

inpx-shelf is derived from [AceAsket/inpx-web](https://github.com/AceAsket/inpx-web) by AceAsket,
which is itself a fork of [bookpauk/inpx-web](https://github.com/bookpauk/inpx-web) by Book Pauk.

inpx-shelf split off from AceAsket/inpx-web at version 1.7.9-rc.8 (commit `1a768e0`) and has been
developed separately since then, with its own name and version numbers starting at 1.0.0. The full
history of both upstream projects is kept in this repository's git history, and the inpx-web
changelog up to the split is in [CHANGELOG-inpx-web.md](CHANGELOG-inpx-web.md).

Thanks to AceAsket and Book Pauk for the work this project is built on.

Like its upstreams, inpx-shelf is released under [CC0 1.0 Universal](LICENSE.md).

Library archives are read with [7-Zip](https://www.7-zip.org/) by Igor Pavlov, compiled to WebAssembly by
[7z-wasm](https://github.com/use-strict/7z-wasm); 7-Zip is licensed under the GNU LGPL with the unRAR restriction.
