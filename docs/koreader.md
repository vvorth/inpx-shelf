# Синхронизация прогресса KOReader

inpx-shelf может работать сервером для встроенного плагина KOReader «Progress sync» (тот же протокол, что у `koreader-sync-server`): место чтения синхронизируется между устройствами с KOReader.

* KOReader узнаёт книгу по хешу файла (partial MD5). inpx-shelf запоминает хеш каждого файла, который отдаёт: скачивание через OPDS и веб-интерфейс в любом формате (в том числе сконвертированный EPUB/KEPUB) и книги, отправленные на Kobo. Для таких книг процент прочитанного попадает в «Продолжить чтение» веб-читалки при каждой отправке из KOReader, если отличается от позиции в веб-читалке: протокол не передаёт время чтения, поэтому позиция считается новой на момент отправки, даже если на устройстве книга открыта на старом месте; читалка откроет книгу на том же проценте. Позиция больше 95%, пришедшая после меньшей, отмечает книгу прочитанной в профиле. Обратно, из веб-читалки в KOReader, позиция не передаётся
* прогресс книг, которых inpx-shelf не узнал (скачаны в другом месте, скачаны до включения синхронизации, файл изменён на устройстве), тоже хранится и синхронизируется между устройствами KOReader, но в веб-читалку не попадает
* в KOReader должен быть выбран способ определения документа по умолчанию — «Binary» (по содержимому файла); при способе «Filename» книги из inpx-shelf не узнаются
* прогресс хранится в профиле (`reading-lists.json`) и входит в бэкап; связь хешей файлов с книгами — в `state.sqlite`

Включение (по умолчанию выключено):

```sh
-e INPX_KOSYNC_ENABLED=true
```

| Переменная окружения | Назначение | По умолчанию |
| --- | --- | --- |
| `INPX_KOSYNC_ENABLED` | Включить синхронизацию прогресса KOReader | `false` |

Подключение KOReader:

1. Откройте «Профиль и устройства» → «Устройства», в блоке KOReader скопируйте адрес сервера (`https://books.example.com/kosync`) и нажмите «Создать пароль». Нужен профиль пользователя: в режиме «Без профиля» синхронизация недоступна. Пароль показывается один раз; «Новый пароль» заменяет старый, и устройства нужно будет подключить заново.
2. В KOReader откройте книгу, затем меню «Инструменты» → «Progress sync» → «Custom sync server» и введите адрес.
3. Там же выберите «Register / Login», введите показанные имя пользователя и пароль и нажмите «Login». Регистрация новых пользователей на сервере отключена.

Пароль KOReader — отдельный от пароля профиля и даёт доступ только к маршрутам `/kosync/`, без SSO. KOReader передаёт MD5 пароля, inpx-shelf хранит только хеш от него. Неудачные попытки входа ограничиваются так же, как вход в профиль. При доступе из интернета используйте HTTPS.
