# Audit fixes (2026-10-20)

Fixes for the 20 findings of the repo audit of 2026-10-20 (`dev` @ e4c05cb). Branch `audit-fixes`, one commit per step: `Audit step N: ...`. Delete this plan when every step is done.

## Common requirements

- Smallest complete change. Reuse existing helpers (`writeFileAtomic`, `withFileTransaction`, `utils.hasProp`, `prepareCachedFile`). No new options or dependencies.
- Each behaviour fix has one test that fails without the fix, in the `*-tests.js` module of its area.
- Code comments: short, explain why, in the language of the surrounding code (mostly Russian).
- A user-facing change gets a line in `CHANGELOG.md` under `Не выпущено`; a changed behaviour updates its doc in `docs/`.
- Done when: the step's tests pass, `npx eslint --quiet server shared scripts build client --ext .js,.vue` is clean, and `npm run test:release` ends with `fail 0`.
